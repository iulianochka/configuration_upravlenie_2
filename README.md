# Dependency Graph Visualizer - Variant 16

Инструмент визуализации графа зависимостей пакетов (формат Alpine Linux, apk).
Проект выполнен в рамках дисциплины "Конфигурационное управление".

## Описание

Программа получает прямые зависимости заданного пакета. Данные берутся
из реального репозитория Alpine Linux (по URL) или из тестового файла.

Реализовано:

- Этап 1: CLI-приложение с настройкой параметров и проверкой ошибок.
- Этап 2: получение прямых зависимостей пакета заданной версии.

Использованы только стандартные библиотеки Python.

## Структура проекта

- `src/main.py` - точка входа, разбор опций, вывод результата
- `src/parser.py` - проверка параметров (этап 1)
- `src/dependencies.py` - получение прямых зависимостей (этап 2)
- `tests/` - тестовые файлы
- `run.sh` / `run.bat` - скрипты с примерами запуска и ошибок

## Параметры командной строки

| Параметр | Описание | По умолчанию |
|----------|----------|--------------|
| `--package` | Имя анализируемого пакета (обязательный) | - |
| `--repo` | URL репозитория или путь к тестовому файлу (обязательный) | - |
| `--version` | Версия пакета, например `1.2.3-r0` | `latest` |
| `--test-mode` | Режим работы с тестовым репозиторием | выключен |

В режиме `--test-mode` параметр `--repo` - путь к файлу, а `--version`
не используется.

## Запуск

```bash
python src/main.py --package <имя> --repo <путь/url> [--version <версия>] [--test-mode]
```

Готовые примеры, включая ошибки: `bash run.sh` (Linux/macOS/Git Bash)
или `run.bat` (Windows).

## Этап 2: получение зависимостей

### Реальный репозиторий Alpine

В `--repo` указывается адрес каталога репозитория для нужной ветки и
архитектуры. Программа скачивает из него файл `APKINDEX.tar.gz`,
распаковывает и разбирает его. Поля записи пакета:

- `P:` - имя пакета
- `V:` - версия
- `D:` - зависимости через пробел

Ограничения версий (`musl>=1.2` -> `musl`) убираются, конфликты (`!pkg`)
пропускаются. Зависимости вида `so:...`, `cmd:...`, `pc:...` выводятся как
в индексе.

Если `--version latest`, берётся первая найденная запись пакета.

```bash
python src/main.py --package curl --repo https://dl-cdn.alpinelinux.org/alpine/latest-stable/main/x86_64
```

### Тестовый режим

Формат тестового файла: на каждой строке пакет и его зависимости.

```text
A: B, C
B: D
C: D
D:
```

```bash
python src/main.py --package A --repo tests/test_graph.txt --test-mode
```

## Обработка ошибок

Программа завершается с кодом 1 и сообщением в `stderr`, если:

- имя пакета или версия имеют недопустимый формат;
- тестовый файл не найден или указана папка;
- URL имеет неверный вид;
- репозиторий недоступен или архив не удалось разобрать;
- пакет или его версия не найдены в репозитории.
