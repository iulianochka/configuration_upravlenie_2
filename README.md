# Dependency Graph Visualizer - Variant 16

Инструмент визуализации графа зависимостей для менеджера пакетов.

## Описание

Проект выполнен в рамках дисциплины "Конфигурационное управление".
На данном этапе реализован минимальный прототип CLI-приложения с конфигурацией.

## Структура проекта

- `src/` - исходный код
- `tests/` - тестовые файлы
- `run.sh` / `run.bat` - скрипты запуска

## Параметры командной строки

| Параметр | Описание | По умолчанию |
|----------|----------|--------------|
| `--package` | Имя анализируемого пакета (обязательный) | - |
| `--repo` | URL-адрес репозитория или путь к файлу (обязательный) | - |
| `--version` | Версия пакета | `latest` |
| `--test-mode` | Режим работы с тестовым репозиторием | `False` |

## Запуск

```bash
python src/main.py --package <имя> --repo <путь/url> [--version <версия>] [--test-mode]
